# 레퍼런스 비교 · 플레이 녹화 (2026-11-03)

`wind.mp4`의 렌더링 스타일을 Godot 4.7 데스크톱 게임으로 옮긴 결과를 레퍼런스 프레임과 나란히 놓은 자료입니다. 왼쪽이 레퍼런스(`docs/style-reference/`), 오른쪽이 Island City입니다. 캐릭터·UI·레벨은 오리지널이며, 비교 대상은 **색·셰이딩·밀도 같은 룩**입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `playtest.mp4` | 자동 플레이 녹화 51초(1280×720, 30fps). 입력 액션을 실제 이벤트로 주입해 플레이 |
| `pair_meadow/beach/path/underwater/village.jpg` | 월드 전용 Shot 카메라 5곳 vs 레퍼런스 |
| `pair_play_meadow/glide/underwater.jpg` | 녹화 중 실제 게임 화면(캐릭터·HUD 포함) vs 레퍼런스 |

## 녹화 구간 (`tests/playtest/autoplay.gd`)

녹화는 다음 순서로 진행되며, 아래 시각은 구간이 시작되는 시점입니다.

```
걷기·달리기(2s) → 꽃 3송이 채집(7s) → NPC 대화(15s) → 인벤토리(21s) → 슬라임 처치(24s) → 활공(28s) → 수영·잠수(33s) → 월드맵(46s) → 종료(51s)
```

재녹화 명령은 아래와 같습니다. 녹화 중 다른 Godot 프로세스가 동시에 돌면 프레임이 정지합니다.

```
godot --path . --write-movie /tmp/take.avi --fixed-fps 30 res://tests/playtest/playtest.tscn
```

## 판정

| 항목 | 일치도 | 근거 |
|---|---|---|
| 팔레트·청록 그림자 규칙 | 높음 | 그림자에 회색·검정 없음, 잔디·물 색이 측정 팔레트 범위 |
| 호수(얕은→깊은 그라데이션, 수련) | 중간 | 민트→청록은 맞으나 레퍼런스의 코발트 깊이감과 반짝임이 약함 |
| 초원 밀도·대비 | 낮음 | 레퍼런스는 덤불·꽃·잔디 결이 화면을 채우고 대비가 강함. 우리는 평평한 초록 면에 가깝다 |
| 수중 | 낮음 | 갓레이·산호·빽빽한 해초 부족, 모래가 빛바램 |
| 카메라 거리 | 낮음 | 레퍼런스는 캐릭터가 화면 높이의 약 1/4, 우리는 약 1/20 |
| 건물 | 중간 | 빨간 지붕은 맞으나 벽이 흰색이 아니라 청회색 |
